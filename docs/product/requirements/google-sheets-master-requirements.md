# Google Sheetsマスター化 要件

## 目的

`text/text.xlsx` で管理している課題リストを Google Spreadsheet に移し、そこをマスターデータとしてアプリから表示・更新できるようにする。

アプリ本体は GitHub Pages で公開し、子どもを含む家庭内の利用者が参照できるようにする。更新は保護者だけができる状態を目指す。

## 前提

- アプリ本体は GitHub Pages で静的サイトとして公開する。
- 課題リストの内容自体は秘密情報として扱わない。
- 参照は子どもを含めてできるようにする。
- 更新は保護者だけができるようにする。
- 静的サイト内に秘密トークンやサービスアカウント鍵は置かない。
- 現在の最新元データは `text/text.xlsx` とする。

## 実シート

- Google Spreadsheet URL: `https://docs.google.com/spreadsheets/d/1IeBaoI0xaE_jQO9TXZBMiEWIoLdxb9tNSdEeCh9Rjbc/edit?usp=sharing`
- Spreadsheet ID: `1IeBaoI0xaE_jQO9TXZBMiEWIoLdxb9tNSdEeCh9Rjbc`
- 確認済みgid: `629015646`
- 共有方針: 公開参照。更新は保護者のGoogleログイン時のみ。

## 方針

### データ管理

- Google Spreadsheet を課題リストのマスターにする。
- Excel のシート構成を基本として、英語、国語、理科、数学、社会などをシート単位で扱う。
- アプリ用に安定した行IDを持たせる。
- アプリ側の `app-data.js` は固定マスターデータではなく、初期表示用またはフォールバック用に寄せる。

### 参照

- 参照は公開された Google Spreadsheet または公開CSVから行う。
- GitHub Pages のアプリは起動時に Google Spreadsheet から最新データを読み込む。
- 読み込みに失敗した場合は、わかりやすいエラー表示を出す。
- 必要なら最後に読めたデータをブラウザ内に一時保存する。

### 更新

- 更新は Googleログインした保護者だけができるようにする。
- GitHub Pages に秘密トークンを埋め込まない。
- Google OAuth を使い、保護者本人の権限で Google Sheets API を呼び出す。
- 子どもが使う画面では、未ログイン時は参照専用にする。
- 保護者がログインした場合だけ、課題状態の更新ボタンを有効にする。

## 対象データ

### 学校側の状態

- 未習
- 学習済
- テスト範囲

### 教材側の状態

- 未
- 丸付け未
- 見直し未
- 見直し完了

状態名は現アプリの表示に合わせつつ、Google Spreadsheet 側では文字列として管理する。

## 必須要件

- Google Spreadsheet から課題リストを読み込める。
- 教科ごとに表示できる。
- 全教科まとめて表示できる。
- 学校側の状態で絞り込める。
- 教材側の状態で絞り込める。
- 未ログイン時は参照専用で使える。
- 保護者が Googleログインすると更新できる。
- 更新内容が Google Spreadsheet に反映される。
- 更新後、画面表示も最新状態になる。
- GitHub Pages に秘密情報を置かない。

## あるとよい要件

- 最後に読み込んだデータをブラウザ内に保持し、オフラインや一時的な読み込み失敗時にも見られる。
- 更新に失敗した場合、画面上で理由を表示する。
- 保護者モードと子どもモードを見た目で区別する。
- Google Spreadsheet のURLやIDを設定画面で変更できる。
- データの形式チェックを行い、必要な列がない場合は警告する。

## 実装ステップ案

1. Google Spreadsheet 用の列定義を決める。
2. `text/text.xlsx` から Google Spreadsheet に移す。
3. アプリから公開データを読み込んで表示する。
4. `app-data.js` 固定データ依存を減らす。
5. Google OAuth のログインを追加する。
6. 保護者ログイン時だけ更新できるようにする。
7. 更新結果を Google Spreadsheet に書き戻す。
8. GitHub Pages 公開用の設定を整える。

## 追加要件: 期末範囲と中間範囲の扱い

- 「範囲」で「期末範囲まで」を選んだ場合、初期状態では `1学期期末` の課題だけを対象にする。
- 「1学期中間も対象」のチェックを入れた場合だけ、`1学期期末` に加えて `1学期中間` の課題も対象にする。
- 「1学期中間も対象」のチェックを外した場合、`1学期中間` の課題は表示対象から外す。
- 画面上でも現在の対象が「1学期期末のみ」か「1学期期末+1学期中間」か分かるように表示する。
- 「授業済みまで」を選んだ場合は、テスト範囲ではなく A列の授業進捗を基準にする。

## 追加要件: 今日やる予定の扱い
- Google Spreadsheet の G列「やったかどうかチェック」は、`〇` / `○` / `完了` / `見直し完了` を完了として扱う。
- G列に日付が入っている場合、その日付は完了ではなく「やる予定日」として扱う。
- 画面の「条件」には `未完了のみ` / `今日やるやつ` / `完了含む` を同列の選択肢として置く。
- `今日やるやつ` を選んだ場合は、予定日が今日で、まだ完了になっていない課題だけを表示する。
- 日付入りの課題は通常の未完了課題としても残す。予定日が入っているだけでは完了扱いにしない。
