# のこりノート

既存の学習計画から独立した、教材・単元別の進捗一覧。Driveの目次画像をAIが読み取り、14ファイルから初期カタログを作成しています。問題ページの丸印や過去のアプリの状態は進捗に引き継いでいません。

## 起動

公開URL: https://tsurezurecoding.github.io/myhomework/learning-tracker/

スマートフォンや別のPCからも開けます。進捗は端末・ブラウザごとの保存です。ローカル版から移す場合は、ローカル版でバックアップを書き出し、公開版で読み込んでください。

このディレクトリで `node serve.mjs` を実行し、http://127.0.0.1:8765 を開きます。静的なHTML / CSS / JavaScriptだけで動作し、外部ライブラリは不要です。`file://` ではモジュールを読み込めないためHTTPで起動してください。

Windowsでは `powershell -File .\start.ps1` でも起動できます。Node.jsが必要です。同じURL・同じブラウザで使うと、記録を引き継げます。

## 使い方

1. 教材を開き、「ここまで終わった」で完了した最後の単元を選びます。
2. 飛ばした単元は「未着手」に戻します。途中のものは「途中」にしてメモを残せます。
3. 残りがわかっている教材は「未確認をすべて未着手にする」で初期確認を終えます。
4. 一覧では「残り・未確認」「途中」などで絞り込みます。「対象外」は完了率の分母と残りから除きます。
5. 変更は同じブラウザのlocalStorageに保存されます。別の端末への移動やブラウザのデータ削除前にバックアップJSONを保存してください。自動クラウド同期はありません。

## 2学期期末の範囲（2026年11月18日〜20日）

初期表示は「2学期期末」です。学校配布の範囲表を `app/test-ranges/final-exam-data.js` に転記し、教材目次との対応を `exam-ranges.js` に設定しています。

- JOYFUL本誌p.52〜83、理科1のワークp.62〜74、理科2の指定問題はページで対応づけています。
- チャレンジ・テスト対策は単元名で対応づけています。一部だけが範囲の単元には対象部分を表示します。
- 社会のページから単元を断定できないものなどは「要確認」です。数学・社会の学校ワークなど、目次を未取り込みの教材は元の範囲表で確認してください。
- 教材をひらき、各単元の「期末の範囲設定」を変更できます。「範囲外の単元も表示して設定する」で除外した単元を戻せます。
- 表示・進捗集計・一括完了は選んだ範囲に対応します。「完了」は単元全体の記録なので、範囲の部分だけ終えた場合は「途中」とメモを使います。
- 範囲設定は進捗と別のキーに保存し、既存の進捗ID・完了状態を維持します。バックアップは範囲設定を含み、以前の形式も読み込めます。

## 取り込みと出典（教材カタログ）

- `sources.json`: 取得日、元のDriveファイル名・ID・URL。
- `catalog.js`: 教科、教材、単元、教材のページ／回番号、PDFの出典ページ。
- チャレンジの教科書対応ページは課題ページとして使用していません。
- 理科ワークのページ範囲は次の単元の開始前までとして整理し、最後の終了ページは未確定と表示。
- JOYFULは付属ノート目次にある「本誌のページ」を採用。
- 未取り込みの教材は画面の「取り込んだ教材について」で表示。フォルダ全体の取り込み完了を意味しません。
- PDFを追加してこのチャットに取り込みを依頼すると、目次を読んでカタログを追加できます。ブラウザからDriveを自動巡回・OCRする機能は未実装です。
- カタログ更新時は既存の単元IDを維持してください。改訂で単元が変わる場合は新IDにします。進捗データをカタログに混ぜないでください。
- 新しい教材の表記揺れを無理に統合せず、教材ごとの完了を管理します。
